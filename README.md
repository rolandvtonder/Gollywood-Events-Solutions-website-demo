# Gollywood Events Solutions — website demo

A five-page site for Gollywood Events Solutions: a scroll-choreographed home page, then Services, Equipment Hire, Gallery and Contact (quote requests go to WhatsApp).

Built with Vite, React, TypeScript, Tailwind CSS v4 and Motion.

## Run it locally

```bash
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Edit the content

Contact details, services, hire items and gallery photos all live in `src/site.ts`. Photos are in `public/assets/`.

The photos in this demo are free stock images from Unsplash and are placeholders for the business's own event photos.
